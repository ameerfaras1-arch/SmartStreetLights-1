☀️ 1. Ambient Light Automation (LDR Sensor)

The LDR photocell monitors natural lux levels. Above 600 Lux, lamps remain completely OFF. Below 100 Lux, lamps turn ON at 30% standby power.

Logic Rule: If LDR > 500 Lux ➔ Mode: OFF (0W)
Night Standby: If LDR < 50 Lux & PIR == Idle ➔ Dimmed (30%, 45W)

🚗 2. Dynamic Motion Dimming (PIR Sensor)

When movement is detected, lights ramp immediately to 100% (150W). Once the entity passes, a decaying timer returns the lamp to 30% standby.

Savings Math: Baseline 150W all night = 1.80 kWh
IoT Smart: 45W idle (70%) + 150W peak (30%) = 0.76 kWh (~58% to 65% energy saved)

🏗️ System Architecture & IoT Hardware Specification

Technical blueprint for College Project Demonstration, Hackathon, and Viva Voce.

🔌 Pole Hardware Node

  • Microcontroller: ESP32 Dual-Core / Arduino Nano with LoRa SX1276
  • Ambient Light: LDR Photocell sensor module with LM393 Comparator
  • Motion Detection: HC-SR501 PIR sensor / RCWL-0516 Microwave Radar
  • Current Sensing: ACS712 (5A/20A) Hall-effect sensor for blown lamp & short circuit detection
  • Driver: PWM MOSFET IRF520 or 230V AC Optocoupled Triac dimmer
  • Power: 12V DC Solar Battery / 230V AC SMPS with buck converter

📡 Communication Protocol

  • Field Mesh: LoRaWAN 865-867 MHz (India Band) for long-range pole-to-gateway telemetry (up to 12 km)
  • Gateway: RAK Wireless / Raspberry Pi LoRaWAN Gateway
  • Cloud Protocol: MQTT over TLS (Port 8883) with JSON payloads
  • Backend: Cloud IoT Broker + REST API + WebSockets for real-time dashboard push
